========================================
PHASE 2: PLAYBACK SYSTEM - SIMPLE EXPLANATION
========================================

WHAT IS PHASE 2?
Phase 2 is the "movie player" for your recorded gameplay. It reads the .gtareplay file you created in Phase 1 and brings it back to life in the game world.

HOW IT WORKS (SIMPLE TERMS):

1. LOADING THE REPLAY
   - When you press F10, the mod opens your .gtareplay file
   - It reads all the "snapshots" (frames) you recorded
   - Each snapshot contains: where people were standing, where cars were driving, what the weather was, etc.

2. FREEZING THE GAME'S BRAIN
   - The game normally has an "AI brain" that spawns random people and cars
   - We turn this OFF so the game doesn't interfere with our replay
   - This is like clearing a stage before a performance

3. SPAWNING THE ACTORS
   - For each person or car in the replay, we create a "dummy" version
   - These are real game entities, but WE control them, not the game's AI
   - Think of them as puppets on strings

4. FRAME-BY-FRAME CONTROL
   - Every single frame (60 times per second), we:
     * Read the next snapshot from the replay file
     * Move each puppet to exactly where it should be
     * Rotate it to face the right direction
     * Update its health, speed, colors, etc.
   
   - This creates the illusion that the recorded scene is "playing back"

5. CLEANUP
   - If a puppet gets too far from the camera (300 units), we delete it
   - This prevents lag and keeps performance smooth
   - When new entities come into view, we spawn them

6. SAFETY FEATURES (DEFENSIVE ARCHITECTURE)
   - Before touching any entity, we CHECK if it still exists
   - We use safe "setter functions" instead of raw memory writes
   - If something goes wrong, we skip that entity instead of crashing
   - We validate model IDs before spawning (no invalid models)
   - We check for "fade out" flags (entities being removed by game)

========================================
CONTROLS:
========================================

F9  = Start/Stop RECORDING
F10 = Start/Stop PLAYBACK

You CANNOT record and playback at the same time.

========================================
TESTING WORKFLOW:
========================================

1. Load your game, go to a busy area (e.g., Grove Street)
2. Press F9 to start recording
3. Walk around, let traffic pass, watch peds walk by
4. Press F9 to stop (creates "replay_YYYYMMDD_HHMMSS.gtareplay")
5. Rename that file to "test_replay.gtareplay"
6. Reload your save (same location)
7. Press F10 to start playback
8. Watch the magic happen - everything replays exactly as recorded!

========================================
TECHNICAL NOTES (FOR YOUR UNDERSTANDING):
========================================

Why is this "defensive"?
- GTA SA's memory is fragile. Other mods, the game itself, or even random bugs can delete entities unexpectedly
- Our code ALWAYS checks "does this entity still exist?" before touching it
- If an entity is gone, we gracefully skip it instead of crashing (0xC0000005 Access Violation)

Why do we disable game AI?
- If we don't, the game will spawn random peds/vehicles that interfere with our replay
- The game might also try to control our "dummy" entities, causing conflicts
- By disabling AI, we have complete control over the world

Why do we clean up distant entities?
- GTA SA has entity pool limits (max 140 peds, max 110 vehicles)
- If we spawn too many, the game crashes or refuses to spawn more
- By removing distant entities, we free up pool slots for new ones

This is production-quality code designed to be rock-solid!
